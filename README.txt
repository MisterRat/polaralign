Simple Polar Align for Phones

This is a Progressive Web App that can be opened and run from any browser and some browsers, like Chrome, let you save it to your phone as an offline application.

Create a folder on your website /polaralign
and put all the files in it

The app was designed to be used with the phone being held either perpendicular or parallel to the tracker.  The MoveShootMove Phone Mount works great for both orientations.
